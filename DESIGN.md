# Identité Visuelle

## Palette de couleurs

| Couleur | Code HEX | Usage |
|---------|----------|-------|
| Bleu foncé | `#010586` | Dégradés, texte sur fond clair |
| Bleu principal | `#0a6bc7` | Couleur principale, titres, accents |
| Bleu clair | `#72d6f2` | Bouton retour, accents secondaires |
| Blanc | `#ffffff` | Arrière-plans, texte sur fond foncé |

## Applications

### Dégradés
```css
background: linear-gradient(135deg, #0a6bc7 0%, #010586 100%);
```
Utilisé pour :
- Fond de l'application
- Affichage des points
- Boutons principaux
- Résumé du poids

### Couleurs d'état
- **Positif** : `#10b981` (vert)
- **Négatif** : `#ef4444` (rouge)
- **Neutre** : `#666` (gris)
